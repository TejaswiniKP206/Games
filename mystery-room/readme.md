# 🔍 Mystery Room – Case 001: The Missing Diamond

A 2D mystery investigation game developed using **Python and Pygame**. Explore a mysterious room, investigate objects, and collect hidden clues to uncover the story behind a missing diamond.

## 🎮 About the Game

Mystery Room is an investigation-based game where players explore an environment and search for important evidence.

In Case 001 – *The Missing Diamond*, players investigate a room containing hidden clues related to a mysterious incident.

The current version focuses on **room exploration and clue collection**. The final mystery-solving and suspect identification mechanics have not yet been implemented.

## ✨ Implemented Features

- **2D Game Environment:** Explore an interactive room.
- **Player Movement:** Move around using keyboard controls.
- **Clue Investigation:** Find and interact with hidden clues.
- **Three Collectible Clues:** Investigate documents, a bookshelf, and a photograph.
- **Evidence Popups:** View details about discovered clues.
- **Investigation Notebook:** Keep track of collected evidence.
- **Interactive Gameplay:** Explore the room and discover all available clues.

## 🕵️ Case 001 – The Missing Diamond

The game currently contains three clues:

1. **Desk Documents:** A torn document mentioning a secret midnight meeting.
2. **Bookshelf:** A hidden golden key.
3. **Photograph:** An image showing someone near the diamond cabinet.

Players can explore the room and collect all three clues.

## 🚀 How to Run

1. Download or clone the repository.
2. Install Python.
3. Install Pygame:

   ```bash
   pip install pygame
   ```

4. Run the game:

   ```bash
   python main.py
   ```
