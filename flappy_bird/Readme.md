# 🐤 Flappy Bird

A fun browser-based arcade game built using **HTML, CSS, and JavaScript**.

## 🎮 About

Control a cute little bird, dodge incoming pipes, and try to achieve the highest score!

## ✨ Features

- Cute bird character with image sprite.
- Smooth movement and gravity physics.
- Randomly generated pipes.
- Collision detection.
- Live score and best score tracking.
- Best score saved using Local Storage.
- Restart functionality.
- Keyboard, mouse, and touch controls.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Canvas API
- Local Storage

## 🚀 How to Run

1. Open the `Flappy-Bird` folder in VS Code.
2. Open `index.html` using Live Server.
3. Start playing!

## 🎯 Controls

| Control | Action |
|---|---|
| SPACE / UP | Fly |
| Mouse Click | Fly |
| Touch | Fly |
