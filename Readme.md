# 🎮 Games Collection

Welcome to my **Games Collection** — a repository featuring small, interactive games developed while exploring game development, programming concepts, and creative design.

This collection includes games built using **Python, Pygame, HTML, CSS, and JavaScript**.

Each project focuses on different aspects of game development, including player interaction, animations, collision detection, and game logic.

## 🕹️ Games

### 🔍 1. Mystery Room – Case 001: The Missing Diamond

**Tech Stack:** Python, Pygame

**Status:** 🚧 Work in Progress

A 2D mystery investigation game where players explore a room and search for hidden evidence related to a missing diamond.

**Features:**
- Interactive 2D room exploration.
- Keyboard-based player movement.
- Three hidden clues to discover.
- Evidence popups displaying clue details.
- Investigation notebook for collected evidence.

**Development Status:**

The room exploration and clue collection mechanics are implemented.

The mystery-solving system, suspect identification, and final case resolution are **not yet implemented**.

📂 [Explore Mystery Room](./Mystery-Room/)

### 🐤 2. Flappy Bird

**Tech Stack:** HTML5, CSS3, JavaScript

**Status:** ✅ Playable

A browser-based arcade game where players control a cute bird and navigate through moving pipes to achieve the highest score.

**Features:**
- Cute bird character using an image sprite.
- Gravity-based flying mechanics.
- Randomly generated obstacles.
- Collision detection.
- Live score tracking.
- Best score saved using Local Storage.
- Restart functionality.
- Keyboard, mouse, and touch controls.

📂 [Explore Flappy Bird](./Flappy-Bird/)

## 🚀 Getting Started

### Mystery Room

1. Navigate to the `Mystery-Room` folder.
2. Install Pygame:

   ```bash
   pip install pygame
   ```

3. Run the game:

   ```bash
   python main.py
   ```

### Flappy Bird

1. Navigate to the `Flappy-Bird` folder.
2. Open `index.html` in your browser or using VS Code Live Server.
3. Start playing!

No additional dependencies are required.
